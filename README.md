# Employee Payroll App – Employee Registration
## Overview
This project implements a simple **Employee Registration System** using Java.  
It demonstrates important **Object-Oriented Programming (OOP)** concepts such as encapsulation, composition, validation using regular expressions, and custom exception handling.
The application allows a new employee to register by entering their personal and account details. The system validates the input, creates the necessary objects, and stores the employee information.
---
## Features
- Validate **Employee ID**, **Email**, and **Phone number** using Regular Expressions
- Store employee information using **encapsulated classes**
- Create **UserAccount credentials** for login
- Encrypt password before storing
- Persist employee data to a file
- Custom **ValidationException** handling
---
## Key Concepts Used
- **Encapsulation** – Private fields with controlled access
- **Constructor Initialization**
- **Method Overriding** – `toString()`
- **Regular Expressions (Regex)** – Input validation
- **Composition** – `Employee` has a `UserAccount`
- **Custom Exception Handling**
